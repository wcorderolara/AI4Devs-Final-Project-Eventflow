## Mantenimiento y sincronización (matriz viva)

Esta matriz se mantiene **sincronizada** con las User Stories mediante un generador determinista:

1. **Fuente de verdad:** la sección `## 🔗 Traceability` y la metadata de cada
   [`management/user-stories/US-*.md`](../user-stories). Cualquier alta o cambio de trazabilidad
   se hace **en la US**, no aquí.
2. **Regenerar la matriz** tras crear o editar una US:
   ```bash
   node scripts/generate-traceability-matrix.mjs
   ```
3. **Validar cobertura** (no destructivo; útil en revisión o CI opcional, AC-05):
   ```bash
   node scripts/generate-traceability-matrix.mjs --check
   ```
   Falla (exit 1) si la matriz quedó desactualizada (EC-02) o si alguna US no aparece.
   La validación es **no bloqueante** por diseño (se sugiere `continue-on-error: true` si
   se cablea en un workflow).
4. **US transversales (EC-01):** se marcan `Transversal` automáticamente cuando no declaran
   ningún ID `FR-`/`UC-`/`BR-`; **no se inventan** IDs (VR-03).

> (a) — ver [`ADR-Index.md`](ADR-Index.md) (US-147). La **validación/reporte de gaps** FRD/UC/BR
> por US es una historia separada (PB-P3-009), fuera de este alcance.
